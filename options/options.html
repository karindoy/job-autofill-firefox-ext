    Everything is stored locally with browser.storage.local. No account, no server, no analytics.

    Fill this once. The extension matches each job-application field by its label, so you do not have to map fields by hand — and anything it cannot guess is still one click away in the popup.

    Personal & contact

    The identity fields almost every application asks for.

    Professional links

    Current role

    Used for “most recent employer”, “job title at recent employer”, work-experience editors and “skills used in this position”.

    Experience history

    Previous roles. They appear as alternatives when you pick a value for “Company” or “Job title”.

    Education

    Used for school, degree and field-of-study fields.

    Skills & languages

    Skills feed chip/tag fields. The first primary skill is used when a field only accepts one value.

    Languages

    Preferences

    Compensation, experience totals and the dropdowns at the end of most applications.

    Eligibility & EEO

    Work-authorization questions and voluntary self-identification. “Decline to self-identify” is respected by the matcher.

    Saved answers

    For questions that are not built in. Use the field label as the key (for example “notice period” or “why do you want to work here”) and the answer as the value. The popup can also save these for you with one click.

    Settings

    How aggressive the extension should be.

    Keyboard shortcuts Change them in Firefox’s extension shortcut settings.
    AltShiftF fill page AltShiftP pick a field

    Import & export

    Back up the profile, move it to another Firefox profile, or start from the included example.

    The example profile is built from the CV in this repository, so you can test the demo form immediately and then edit the values.

    Privacy

    Your profile never leaves this browser. The extension has no network code and requests no analytics permission. Auto-fill only runs on pages you visit and can be disabled per site above.
